Thought2Build

Live product

A GenAI workspace that turns rough product ideas into build-ready plans.

  1. Spec
  2. Plan
  3. Harness
  4. Tasks

Each stage sits behind a review gate.

A FastAPI workspace that takes an idea through four stages and hands back four build-ready artifacts: spec, plan, harness and tasks.

  • Multi-provider LLM routing across Anthropic, OpenAI and Google, with bring-your-own-key credentials, OAuth sign-in and a credit-metered free tier.
  • Harness-first generation. Validation assets are produced before code, and every task traces back to a requirement, so the output can drive AI coding agents directly.

Built with FastAPI, multi-provider LLM routing and OAuth.

SentinelIQ

Winner of the TCS Kochi AI Hackathon

Predictive maintenance and fault diagnosis.

  1. Coordinator
  2. Guardrail
  3. Diagnosis
  4. Approval

A platform modelled on a 15-machine plant with replayed telemetry, where 41 versioned features feed scikit-learn predictors for failure probability, fault mode, remaining useful life and fused risk.

  • An agent workflow of coordinator, guardrail, diagnosis and approval stages across four role-based personas, with planner sign-off required before any immutable ERP write.
  • Numbers stay off the LLM path. Optional Gemini narration is circuit-broken with a deterministic template fallback, and releases gate on balanced-accuracy and downtime KPI thresholds.

Built with scikit-learn, an agent workflow, role-based access control and Google Gemini.

Covenant Radar

Finalist in the TCS National Hackathon

Credit-risk early warning for commercial loans.

Forecasts commercial loan covenant breaches at 30, 60 and 90 days, keeping deterministic covenant arithmetic separate from behavioural risk signals.

  • A single guarded LLM call site: input masking, provider-registry checks, token-budget ceilings, prompt-hash versioning and an append-only record of every attempt and refusal.
  • A six-step nightly pipeline with eight-role access control, maker-checker approvals and a hash-chained audit trail, released behind an evaluation harness with per-category score floors.

Built with a guarded LLM call site, an evaluation harness and a hash-chained audit trail.
